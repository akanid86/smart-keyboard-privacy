นโยบายความเป็นส่วนตัว (ภาษาไทย)

Smart Keyboard · ไทย / English ("ส่วนขยาย") ช่วยตรวจจับข้อความที่อาจพิมพ์ผิดแป้นภาษาไทย–อังกฤษ และเสนอให้ผู้ใช้เลือกแก้ไขด้วยตนเอง เอกสารนี้อธิบายการเข้าถึง การประมวลผล การจัดเก็บ และการเปิดเผยข้อมูลของส่วนขยายเวอร์ชัน 0.2.1

1. ข้อมูลที่เข้าถึงและใช้

  • ข้อความในช่องพิมพ์ที่รองรับ: บนเว็บไซต์ที่ผู้ใช้เปิดใช้งาน ส่วนขยายอ่านข้อความบริเวณตำแหน่งเคอร์เซอร์ (รวมถึงข้อความแชทหรือข้อมูลที่กำลังร่างได้) เพื่อประเมินความเป็นไปได้ของการพิมพ์ผิดภาษา โดยส่งเฉพาะข้อความที่จำเป็นไปยังส่วนประมวลผลภายในส่วนขยายบนอุปกรณ์เดียวกัน
  • ข้อมูลเว็บไซต์ที่เปิดใช้งาน: เก็บที่อยู่เว็บไซต์ระดับ origin (เช่น scheme และชื่อโฮสต์) และสถานะเปิด/ปิดส่วนขยาย เพื่อจดจำการตั้งค่ารายเว็บไซต์
  • การตอบรับคำแนะนำ: หากเปิดระบบเรียนรู้ ส่วนขยายเก็บแฮช 32 บิตของคำหรือคู่คำที่ผู้ใช้กด Apply, Ignore หรือ Undo รวมถึงจำนวนการยอมรับบางรายการ เพื่อปรับคำแนะนำในอนาคต ค่าแฮชเหล่านี้ไม่ใช่การเข้ารหัสที่รับประกันว่าข้อมูลต้นทางจะไม่ถูกอนุมาน

2. วัตถุประสงค์

ใช้ข้อมูลเฉพาะเพื่อระบุข้อความที่น่าจะพิมพ์ผิดรูปแบบแป้นพิมพ์ แสดงคำแนะนำที่ผู้ใช้ตรวจสอบได้ ทำการแก้ไขเมื่อผู้ใช้กด Apply และบันทึกการตั้งค่าการใช้งานตามที่ผู้ใช้เลือก ไม่มีการแก้ไขอัตโนมัติโดยปราศจากการยืนยันในเวอร์ชันนี้

3. การประมวลผลและการส่งข้อมูล

การตรวจจับและเรียนรู้ทำงานภายในเบราว์เซอร์ของผู้ใช้ โค้ดส่วนขยายเวอร์ชันนี้ไม่มีระบบส่งข้อความที่พิมพ์ การตั้งค่าหรือข้อมูลการเรียนรู้ไปยังเซิร์ฟเวอร์ของผู้พัฒนาหรือบุคคลที่สาม และไม่มีบริการวิเคราะห์พฤติกรรมออนไลน์หรือโฆษณาติดตามผู้ใช้ ทั้งนี้เว็บไซต์ที่ผู้ใช้กำลังใช้งานอาจมีการรับส่งข้อมูลตามการทำงานของเว็บไซต์นั้นเอง ซึ่งอยู่นอกเหนือการควบคุมของส่วนขยาย

4. การจัดเก็บ ระยะเวลาเก็บ และการลบ

สถานะเปิดใช้งานรายเว็บไซต์ การตั้งค่าการเรียนรู้ และข้อมูลแฮชการตอบรับ ถูกเก็บด้วย chrome.storage.local บนเครื่องผู้ใช้ โดยคงอยู่ข้ามการเปิดเบราว์เซอร์จนกว่าผู้ใช้จะลบหรือติดตั้งส่วนขยายใหม่ ผู้ใช้สามารถปิดและล้างข้อมูลการเรียนรู้ผ่านเมนูส่วนขยายได้ การปิดเว็บไซต์ไม่ได้ลบรายการสถานะเว็บไซต์ทั้งหมดโดยอัตโนมัติ การล้างข้อมูลของส่วนขยายผ่าน Chrome จะลบข้อมูลที่จัดเก็บในเครื่องตามพฤติกรรมของเบราว์เซอร์

5. ข้อมูลอ่อนไหวและข้อจำกัด

ส่วนขยายออกแบบให้ข้ามช่องรหัสผ่าน รหัสยืนยัน ข้อมูลการชำระเงิน และช่องที่ระบุว่าอ่อนไหวด้วยชนิดช่องและข้อมูลกำกับ อย่างไรก็ตาม เว็บไซต์บางแห่งอาจใช้ช่องที่มีโครงสร้างไม่มาตรฐาน จึงไม่สามารถรับประกันว่าจะระบุช่องอ่อนไหวได้ทั้งหมด ผู้ใช้ควรปิดส่วนขยายในเว็บไซต์ที่ไม่ต้องการให้ตรวจข้อความ

6. การเปิดเผยและการใช้ข้อมูลที่จำกัด

ผู้พัฒนาไม่ขายข้อมูลผู้ใช้ ไม่ส่งข้อมูลข้อความเพื่อโฆษณา ไม่ใช้ข้อมูลเพื่อการประเมินเครดิต และไม่นำข้อมูลไปใช้เพื่อวัตถุประสงค์อื่นที่ไม่เกี่ยวข้องกับการทำงานหลักของส่วนขยาย ข้อมูลที่ส่วนขยายประมวลผลจะไม่ถูกเปิดให้ผู้พัฒนาอ่านผ่านบริการออนไลน์

7. การเปลี่ยนแปลงนโยบายและการติดต่อ

หากมีการเปลี่ยนแปลงวิธีใช้หรือจัดเก็บข้อมูล จะปรับปรุงนโยบายนี้ก่อนหรือพร้อมกับการเปลี่ยนแปลงนั้น สำหรับคำถามด้านความเป็นส่วนตัว โปรดใช้ช่องทางติดต่อผู้พัฒนาที่ระบุในหน้ารายการ Smart Keyboard บน Chrome Web Store

Privacy Policy (English)

Smart Keyboard · ไทย / English (the “Extension”) helps detect text typed using the wrong Thai or English keyboard layout and lets users review and manually apply suggestions. This policy describes the data accessed, processed, stored, and disclosed by version 0.2.1.

1. Data accessed and used

  • Text in supported editable fields: On sites explicitly enabled by the user, the Extension reads text near the cursor (which may include drafted chat or message content) to identify potential keyboard layout errors. Relevant text is processed by the Extension's local service worker.
  • Enabled website settings: The Extension stores website origins (such as scheme and hostname) and on/off preferences to remember where it is enabled.
  • Suggestion feedback: If local learning is enabled, the Extension stores 32-bit hashes representing accepted, ignored, or undone suggestions and certain per-item acceptance counts. These hashes are not cryptographic protection and may be susceptible to inference attacks.

2. Purpose

Data is used only to detect likely keyboard layout errors, show reviewable suggestions, apply a correction when a user chooses Apply, and remember user-selected preferences. Version 0.2.1 does not automatically modify text without confirmation.

3. Processing and sharing

Detection and learning run locally in the browser. This version does not send typed text, stored preferences, or learning data to developer or third-party servers, and includes no external analytics or advertising trackers. Websites themselves may transmit or process content independently when you use them; this is outside the Extension's control.

4. Storage, retention, and deletion

Enabled-site settings, learning preferences, and hashed feedback are kept on your device using chrome.storage.local, including across browser sessions, until cleared or the Extension is uninstalled. You can disable and reset learning from the Extension popup. Disabling a site does not automatically erase every stored site preference. Clearing the Extension's stored data through Chrome removes local storage according to browser behavior.

5. Sensitive inputs and limitations

The Extension is designed to skip passwords, verification codes, payment details, and other sensitive fields identified by input types and metadata. Nonstandard website implementations may not be reliably recognized. Users can turn off the Extension on sites where they do not want editable text processed.

6. Limited use

The developer does not sell user data, use entered text for advertising, use it for creditworthiness or lending, or transfer the Extension's processed content for unrelated purposes. The Extension provides no online service through which the developer can read the text it processes.

7. Changes and contact

If data practices change, this policy will be updated before or alongside those changes. For privacy questions, please use the developer contact channel listed on the Extension's Chrome Web Store listing.

This policy describes the reviewed v0.2.1 package. Before publishing a newer version, verify that the code and disclosure remain accurate.
