Smart Keyboard · ไทย / English ("ส่วนขยาย") ช่วยตรวจจับข้อความที่พิมพ์ผิดแป้นภาษาไทย–อังกฤษ แก้คำผิดแป้นในโหมดอัตโนมัติตามที่ผู้ใช้เปิดเลือก และแปลข้อความที่เลือกด้วย Chrome Translator บนอุปกรณ์ ผู้ใช้สามารถเลือกเปิดเว็บไซต์ Google Translate ภายนอกได้ด้วยตนเอง เอกสารฉบับร่างนี้ครอบคลุมเวอร์ชัน 0.5.4

1. ข้อความที่ใช้สำหรับแก้ไขผิดแป้น

เมื่อเปิดส่วนขยายบนเว็บไซต์หนึ่ง ๆ ระบบอ่านข้อความบริเวณเคอร์เซอร์ในช่องพิมพ์ที่รองรับเพื่อประเมินการพิมพ์ผิดแป้นและแสดงคำแนะนำ การประมวลผลเกิดขึ้นภายในส่วนขยายบนเครื่องของผู้ใช้ หากผู้ใช้เปิด Layout Auto สำหรับเว็บไซต์นั้น ระบบอาจแก้เฉพาะคำที่เข้าเกณฑ์ความมั่นใจสูงโดยอัตโนมัติ โดยไม่กดส่งข้อความหรือส่งแบบฟอร์ม ผู้ใช้ปิด Auto และใช้ Undo ได้

2. การแปลภาษาในเครื่อง (ค่าเริ่มต้นปิด)

เมื่อผู้ใช้เปิด Translation และคลุมดำข้อความ แล้วเลือก "Translate with Smart Keyboard" จากเมนูคลิกขวา ระบบจะใช้เฉพาะข้อความที่เลือกเพื่อแปลด้วย Chrome Translator API บนอุปกรณ์ คำแปลและความหมายเพิ่มเติมจากพจนานุกรมขนาดเล็กที่มากับส่วนขยายจะแสดงในป๊อปอัพ ไม่มีการอ่านข้อความรอบข้างเพื่อช่วยตีความ ในช่องพิมพ์จะเปลี่ยนข้อความเฉพาะเมื่อผู้ใช้กดยืนยัน Apply; ข้อความบนหน้าเว็บแบบอ่านอย่างเดียวจะไม่ถูกแก้ การดาวน์โหลดโมเดลภาษาครั้งแรกอาจดำเนินการโดย Chrome

3. การเปิด Google Translate ภายนอก (ต้องกดโดยชัดแจ้ง)

หากผู้ใช้คลิกปุ่ม Google Translate ระบบจะสร้างลิงก์ไปยัง translate.google.com โดยใส่ข้อความต้นฉบับที่ผู้ใช้คลุมดำลงใน URL พร้อมภาษาต้นทางและปลายทาง เมื่อเปิดแท็บ Google จึงสามารถรับข้อความดังกล่าวได้ ข้อความใน URL อาจปรากฏในประวัติการท่องเว็บและได้รับการจัดการตามนโยบายของ Google ส่วนขยายไม่ส่งข้อความไป Google โดยอัตโนมัติ สำหรับข้อความยาวเกินเกณฑ์ลิงก์จะให้คัดลอกต้นฉบับและเปิดเว็บเปล่าเพื่อให้ผู้ใช้วางเอง

4. การตั้งค่าและข้อมูลที่บันทึกในเครื่อง

  • บันทึกสถานะเว็บไซต์ที่เปิดใช้ ตัวเลือก Auto และ Translation และข้อมูลการตั้งค่าไว้ใน chrome.storage.local บนอุปกรณ์
  • การเรียนรู้จาก Apply / Ignore / Undo หากเปิดไว้ จะเก็บคีย์แฮช 32 บิตและจำนวนการยอมรับบางรายการ ไม่เก็บข้อความเต็มเพื่อการเรียนรู้โดยอัตโนมัติ แฮชชนิดนี้ไม่ใช่การเข้ารหัสที่ไม่สามารถย้อนอนุมานได้
  • คำศัพท์ส่วนตัวที่ผู้ใช้เพิ่มเองอาจถูกบันทึกเป็นข้อความที่อ่านได้ในเครื่อง โดยปิดฟังก์ชันไว้เป็นค่าเริ่มต้น
  • เมื่อใช้หน้าต่างแปลสำรอง ข้อความที่เลือกอาจถูกพักชั่วคราวใน chrome.storage.session และถูกลบเมื่อหน้าต่างอ่านข้อมูล ไม่มีการเก็บประวัติคำแปลไว้ในส่วนขยาย
  • ข้อมูลการตั้งค่าระบบสะกดคำรุ่นทดลองเก่าอาจยังอยู่ในเครื่องเพื่อรักษาข้อมูลเดิม แต่ไม่ได้ทำงานตรวจสะกดในรุ่นนี้

5. สิทธิ์และข้อมูลอ่อนไหว

contextMenus ใช้แสดงเมนูแปลข้อความที่เลือก activeTab และ scripting ใช้เข้าถึงหน้าที่ผู้ใช้สั่งแปลเป็นครั้งคราว และการอนุญาตเว็บไซต์เพิ่มเติมเป็นไปตามการเปิดใช้ส่วนขยายของผู้ใช้ ระบบออกแบบให้ไม่แตะช่องรหัสผ่าน ข้อมูลชำระเงิน และรหัสใช้ครั้งเดียว แต่ไม่อาจรับประกันการจำแนกช่องที่เว็บไซต์ออกแบบผิดมาตรฐานได้ทุกกรณี โปรดหลีกเลี่ยงการส่งข้อมูลสำคัญผ่านปุ่มเปิด Google Translate

6. การส่งข้อมูลและการติดต่อ

ส่วนขยายไม่ใช้ระบบ AI ออนไลน์ของผู้พัฒนา ไม่ส่งข้อความผ่านบริการแปลเสียเงิน ไม่ติดตั้ง Telemetry และไม่ขายข้อมูลผู้ใช้ การประมวลผลสำหรับตรวจผิดแป้นและแปลในเครื่องไม่มีการส่งข้อความไปเซิร์ฟเวอร์ผู้พัฒนา การเปิด Google Translate ด้วยปุ่มเป็นข้อยกเว้นที่ผู้ใช้สั่งโดยตรง ทั้งนี้เว็บไซต์อื่นที่ใช้งานอาจประมวลผลข้อความเองตามปกติ สอบถามผู้พัฒนาตามช่องทางในหน้า Chrome Web Store

Privacy Policy (English)

Smart Keyboard Thai / English (the "Extension") detects wrong keyboard-layout input, offers optional per-site automatic layout correction, and provides selected-text translation using Chrome's on-device Translator API. The user may also deliberately open Google Translate for further translation. This draft applies to v0.5.4.

1. Keyboard-layout assistance

On user-enabled sites the Extension processes nearby editable text around the caret locally to detect text entered under the wrong Thai/English layout. If the user separately enables per-site Layout Auto, certain high-confidence words may be replaced automatically. The Extension does not submit messages or forms; Auto can be disabled and corrections can be undone.

2. On-device selected-text translation (off by default)

When enabled, the user selects text and chooses Translate with Smart Keyboard from Chrome's right-click menu. Only the selected text is translated using Chrome's on-device Translator API. Alternative word meanings, when available, come from a small bundled dictionary. The Extension does not read surrounding webpage text for contextual analysis. Read-only website text is never modified; editable selections change only after explicit Apply confirmation. Chrome may download translation models upon first use.

3. Explicit external Google Translate action

If the user clicks Google Translate, the Extension opens translate.google.com with the original selected text and language direction in URL parameters. The selected text is then disclosed to Google as an external service and may appear in browser history. Google's privacy and service policies apply. The Extension never opens Google Translate or sends text to Google without that click. For selections exceeding the conservative URL budget, it instead offers Copy Original and a blank Google Translate page for manual pasting.

4. Local storage

  • Enabled-site origins, feature/Auto preferences and other settings are stored using chrome.storage.local.
  • If learning is enabled, 32-bit hashed feedback keys and limited counters may be stored for Apply/Ignore/Undo. Hashes are not cryptographic protection against guessing.
  • Personal vocabulary explicitly provided by users can be stored as readable local text; this feature is off by default.
  • If in-page translation is unavailable, selected text may be transferred to an Extension-only fallback popup using memory-only chrome.storage.session and deleted when read. No persistent translation history is maintained.
  • Inactive spelling-experiment preferences/data from older versions may remain locally until reset or removal, but spelling correction is not active in v0.5.4.

5. Permissions and sensitive content

The contextMenus permission adds the selection menu; activeTab and scripting permit temporary injection after user action. Optional host permissions apply to enabled sites. Sensitive fields such as passwords, payment details and OTPs are designed to be excluded, but highly custom website fields may not be detected reliably. Avoid using the external Google button with sensitive material.

6. Sharing, limited purpose, and contact

The Extension has no developer-run translation cloud, paid API, telemetry, advertisement tracker or user-data sales. Layout checking and built-in translation are processed locally. External Google Translate is a user-initiated exception as described above. Websites visited may independently transmit information through their own operation. For inquiries, use the developer contact listed in the Chrome Web Store item.
